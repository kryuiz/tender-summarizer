# Tender Summarizer

AI-сервис для автоматического анализа тендерной документации.

Приложение принимает PDF-файлы с тендерной документацией, извлекает текст и с помощью локальной LLM извлекает ключевую информацию:

- сумму контракта;
- сроки выполнения;
- требования к поставщику;
- штрафы и неустойки.

## Возможности

- Загрузка PDF-документов через REST API
- Проверка входных файлов
- Извлечение текста из PDF
- Анализ документов с помощью LLM
- Структурированный JSON-ответ
- Локальная обработка без внешних AI API

## Технологии

- Python 3.14+
- FastAPI
- Pydantic
- HTTPX
- Ollama
- Llama 3.1 8B

## Установка

Клонирование репозитория:

```bash
git clone https://github.com/kryuiz/tender-summarizer.git
cd tender-summarizer
```

Создание виртуального окружения:

```bash
python -m venv .venv
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Установка Ollama и модели:

```bash
ollama pull llama3.1:8b
```

## Запуск

Запуск API:

```bash
uvicorn app.main:app --reload
```

Документация API будет доступна по адресу:

```
http://127.0.0.1:8000/docs
```

## Использование

Отправка PDF-файла:

```bash
curl -X POST \
  -F "file=@document.pdf" \
  http://127.0.0.1:8000/upload
```

Пример ответа:

```json
{
  "filename": "contract.pdf",
  "summary": {
    "contract_amount": "15000000",
    "deadline": "30 календарных дней",
    "requirements": [
      "Соответствие требованиям законодательства"
    ],
    "penalties": [
      "Пеня 1/300 ключевой ставки ЦБ РФ"
    ]
  }
}
```

## Ограничения

- Качество анализа зависит от структуры PDF-документа.
- Сложные документы с большим количеством таблиц могут требовать дополнительной обработки.
- Скорость работы зависит от оборудования и используемой LLM.
